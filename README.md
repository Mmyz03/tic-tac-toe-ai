# Tic Tac Toe AI

A browser-based Tic Tac Toe game where players can either compete against an AI or play locally with another player.

The game includes three AI difficulty levels: Easy, Medium, and Bihar (Impossible). The Impossible mode uses the Minimax algorithm to make optimal decisions, while the other modes provide more relaxed and beatable gameplay.

The project focuses on a clean and responsive interface, smooth game interactions, win/draw detection, restart functionality, and support for both desktop and mobile devices.

Built using HTML, CSS, and Vanilla JavaScript without external frameworks or dependencies.
